# My Personal Portfolio Website

This is my personal portfolio website built using **HTML**, **CSS**, and **JavaScript** without any frameworks or plugins.  
It showcases my skills, projects, and provides contact information in a clean, responsive design.

---

## Features

- Fully responsive layout for mobile, tablet, and desktop devices  
- Clean and modern UI design  
- Custom CSS media queries for various screen sizes  
- Interactive elements built with vanilla JavaScript  
- Semantic HTML structure for accessibility and SEO  

---

## Responsive Breakpoints

| Device Type     | Screen Width      |
|-----------------|-------------------|
| Mobile Small    | 320px             |
| Mobile Medium   | 375px             |
| Mobile Large    | 425px             |
| Tablet          | 768px             |
| Laptop          | 1024px            |
| Laptop Large    | 1440px            |
